# JavaScript Fundamentals

Repository created to document my progress while learning JavaScript, TypeScript and React — as part of the **[O Novo Programador](https://onovoprogramador.com/)** course, studied in parallel with my main Java backend track.

All exercises in this repository were independently developed by me. They are not copies of the course's guided projects — each one is a small, focused exercise built to validate a specific concept, following the same practice pattern used in my [java-fundamentos](https://github.com/RenanQueirozDev/java-fundamentos) repository.

## 📚 Topics Studied

*(filled in as topics are covered)*

**JavaScript**
- Variables, data types, operators, conditionals
- Functions, arrays, objects, loops
- DOM manipulation and events
- Object-Oriented Programming in JS — classes, constructors, encapsulation
- Asynchronous JavaScript — callbacks, Promises, async/await

**TypeScript**
- Types, interfaces, classes

**React**
- Components, props, composition
- Hooks — `useState`, `useEffect`
- Consuming REST APIs — connecting to my own Spring Boot backend

## 🏗️ Architecture & Design

Beyond syntax, this repository also tracks how front-end code is organized and why:

- Component composition and separation of concerns
- State management fundamentals (before reaching for external libraries)
- API integration patterns — how the front-end talks to a real backend, including CORS and async data fetching

Many of these concepts mirror what's studied on the Java side (encapsulation, layered responsibility, REST) — same principles, different syntax and context.
